# Northstar Analytics: quarterly planning sample

This folder is a small company-style repository sample. It contains a quarterly
business review, an operating budget, a project brief, and a slide deck.

## Files

- `quarterly-review.pdf` — executive summary for Q3 2026
- `operating-budget.xlsx` — team-level budget and forecast
- `vendor-onboarding.docx` — internal process brief
- `quarterly-review.pptx` — leadership presentation

These document formats are tracked with Git LFS. In GitHub's file browser,
Git stores and displays a small LFS pointer instead of showing a useful text
diff for the binary content. Cloning with Git LFS installed downloads the real
files. The `.gitattributes` file also includes common archive and design asset
formats; those patterns are ready for future files.

The figures and organization in these documents are fictional examples.
